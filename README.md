# Arquivo de Ajuda — PetClean 🐾

**Sistema Web para Petshop — Fase 1**  
Disciplina: Fundamentos de Sistemas Web — PUCRS  
Ano: 2026 Trimestre 3


## Sobre o Sistema

O **PetClean** é uma plataforma web de comércio de produtos e serviços para cães. O sistema é composto por 5 páginas HTML estáticas interligadas por um menu de navegação comum.


## Informações Técnicas

- Tecnologia: HTML5 semântico puro
- Sem uso de CSS, Bootstrap ou JavaScript (Fase 1)
- Compatível com qualquer navegador moderno (Chrome, Firefox, Edge, Safari)
